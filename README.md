# PAKWK.ONLINE

Website statis untuk GitHub Pages dengan custom domain `pakwk.online`.

## Struktur
- `index.html` — Home
- `about.html` — Tentang Kami
- `articles.html` — Daftar artikel + pencarian sederhana
- `privacy.html` — Kebijakan Privasi dan Integritas Informasi
- `contact.html` — Kontak
- `articles/` — Halaman artikel
- `assets/css/style.css` — Desain responsif
- `assets/js/main.js` — Navigasi mobile dan pencarian
- `CNAME` — Custom domain GitHub Pages

## Deploy
Upload seluruh isi folder ini ke root repository `visjnoe08-tech/pakwkonline`, pertahankan branch `main` dan folder publikasi `/ (root)`. Pastikan GitHub Pages tetap memakai custom domain `pakwk.online`.

Semua link internal menggunakan path relatif. Jangan menghapus file `CNAME`.

## Catatan
Website ini tidak memiliki backend, database, login, atau formulir yang mengirim data. Kontak menggunakan tautan email dan WhatsApp.
